# SocialSTG project page

Anonymous double-blind project page for **Beyond Visibility: Persistent Graph Memory for Visual Social Navigation**.

This static Academic Project Page / Probex-style site deploys through GitHub Pages from the `main` branch.

## Enable GitHub Pages once

Open **Settings → Pages → Build and deployment**, choose **GitHub Actions** as the source, and save. The existing workflow will then publish the site automatically on every push to `main`.

During review, author identities, code links, data identifiers, and citation metadata are intentionally withheld.
